راهنمای ساخت APK فقط با موبایل

۱) در Chrome سایت https://github.com را باز کنید و حساب رایگان بسازید یا وارد شوید.
۲) از + گزینه New repository را انتخاب کنید.
۳) نام مخزن را SAIQ-Demo بگذارید و Public یا Private انتخاب کنید؛ سپس Create repository.
۴) در صفحه مخزن، Add file > Upload files را بزنید و محتویات این ZIP را بارگذاری کنید.
   نکته: فایل‌ها و پوشه مخفی .github نیز باید آپلود شوند. اگر موبایل پوشه مخفی را پنهان کند،
   باید آن پوشه را جداگانه در GitHub ایجاد کنید و فایل workflow را در مسیر
   .github/workflows/build.yml بسازید.
۵) Commit changes را بزنید.
۶) به زبانه Actions بروید و workflow با نام Build SAIQ Demo APK را باز کنید.
۷) پس از پایان موفق، پایین صفحه اجرای workflow بخش Artifacts، فایل SAIQ-Demo-APK را دانلود کنید.
۸) ZIP دانلودشده را باز کنید و app-debug.apk را نصب کنید.

مهم:
- این نسخه فقط نمونه آزمایشی آفلاین است؛ به سرور یا دیتابیس اصلی SAIQ وصل نیست.
- این فرایند نیازمند حساب GitHub و اتصال اینترنت است.
- هرگز رمز سرور، دیتابیس یا اطلاعات مشتریان واقعی را در مخزن بارگذاری نکنید.
