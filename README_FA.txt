SAIQ Demo Android — نسخه آزمایشی

این پروژه نمونه اولیه یک اپ اندرویدی بومی برای نمایش رابط SAIQ است.
امکانات آزمایشی:
- داشبورد و کارت‌های آماری
- ثبت مشتری نمونه در حافظه موقت برنامه
- ثبت پرداخت نمونه
- فهرست مشتریان و قرض‌داران نمونه
- گزارش مالی نمونه

هشدار:
این نسخه به سرور، MikroTik یا دیتابیس MySQL وصل نیست.
اطلاعات با بستن برنامه ممکن است از بین برود و هیچ عملیات مالی واقعی انجام نمی‌دهد.
برای نسخه عملیاتی، سورس وب SAIQ و API امن سرور لازم است.

ساخت APK:
1. Android Studio را روی کامپیوتر نصب کنید.
2. پوشه SAIQ_Demo_Android را باز کنید.
3. منتظر بمانید Gradle Sync کامل شود.
4. از منوی Build گزینه Build Bundle(s) / APK(s) سپس Build APK(s) را انتخاب کنید.
5. APK در مسیر app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.
